# Open Here

Find where your business idea has hidden demand.

Open Here is a Qloo-powered agent for people opening a local business. Give it a concept and a city, and it maps where that taste is stronger than local foot traffic predicts ("taste lift"), shows real competitors, profiles the audience, and drafts a launch playbook grounded in what those people actually like.

Built for the [Qloo Agentic Hackathon](https://qloo.devpost.com/).

## Status

Work in progress.

## Setup

```bash
cp .env.example .env   # add your Qloo key and base URL
```
